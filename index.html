Cómo publicar artículos en el blog

¿Cómo funciona este panel?

Cuando guardás un artículo desde este panel, el cambio se guarda en tu navegador y se descarga el archivo noticias.json actualizado. Para que aparezca en el blog necesitás subir ese archivo a GitHub.

Paso a paso para publicar
1
Creá el artículo en este panel
Completá el formulario con título, categoría, autor, fecha y contenido. Hacé clic en "Guardar artículo".
2
Descargá el archivo JSON
Al guardar, se descarga automáticamente noticias.json. Guardalo en la carpeta content/ de tu proyecto.
3
Subí los cambios a GitHub
Abrí GitHub Desktop (o la terminal), hacé commit del archivo actualizado y push. Netlify detectará el cambio automáticamente.
✓
¡Listo! El blog se actualiza en segundos
Netlify hace el deploy automático cada vez que subís cambios a GitHub. En 1-2 minutos el artículo aparece en el blog.
Comandos Git (si usás terminal)
# Desde la carpeta del proyecto:
git add content/noticias.json
git commit -m "Nuevo artículo: [título]"
git push
